# Research-Driven Self-Correcting AI Coding Agent

An autonomous multi-agent AI system built using LangGraph that researches programming tasks, generates code, validates the output, and automatically corrects errors before producing the final solution.

---

## Features

- Research-based code generation
- Automated code validation
- Self-correction workflow
- Multi-Agent Architecture
- LangGraph Orchestration
- Groq LLM Integration

---

## Workflow

```
Start
 ↓
Research Agent
 ↓
Code Agent
 ↓
Checker Agent
 ↓
Self Correction
 ↓
Final Output
```

---

## Tech Stack

- Python
- LangGraph
- LangChain
